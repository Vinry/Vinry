# Martin Larsson

Enterprise Security Architect at **link22**, based in Sweden. I work with secure systems architecture, enterprise infrastructure, identity, and PKI, combining design with practical implementation.

I hold an **M.Sc. in Information Technology from Linköping University**, specializing in Secure Systems. My research interests include malware scanning and the WebPKI.
